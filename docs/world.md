# 倒影国：olo 的世界

> 本设定为 olo 项目原创。简版故事见 [story.md](story.md)（权威来源），人物卡见 [character.md](character.md)。

> 倒影国里**没有人类**：住着涟漪兽、光鱼和会走路的小水洼。涟漪兽都没有手脚。

## 一、镜子两边

每一面会反光的东西（水面、窗玻璃、手机屏幕）后面，都藏着一个倒过来的世界。人类在这一边，倒影国在那一边。两边谁也过不去：涟漪兽离开光就会散开，人类也穿不过镜面。

屏幕亮起来的时候，就是一面打开的镜子。这一边说的话，会变成一圈涟漪漂到那一边，变成倒着写、会漂的光字。

## 二、倒过来的规矩

- **倒雨**：雨从地上往天上落，落之前脚边先溅起一圈小水花。
- **彩色影子**：东西的影子是彩色的；心情好的那天，影子颜色会更亮。
- **时间跟着光走**：天亮天黑跟着对面屏幕的光，不跟钟表。
- **双月**：镜子两边各有一个月亮，倒影国的那个好像是照着人类那边长的。

## 三、地方

| 地方 | 是什么 |
| --- | --- |
| 倒影湾 | olo 最早漾出来的那片水湾 |
| 雾镜面 | 刚认识时还看不清彼此的那层雾 |
| 镜面边 | 两个世界挨得最近的地方 |
| 光鱼巷 | 光鱼游来游去送口信的小巷 |
| 彩影廊 | 挂满彩色倒影的长廊 |
| 倒雨坡 | 看倒雨最好的小坡 |
| 双月台 | 能同时看见两个月亮的台子 |

网页里可以走动的 2.5D 场景统称**倒影小镇**（广场 / 小屋 / 湖边 / 屋顶）。

## 四、居民

- **涟漪兽**：一颗颗会发光的小水滴，一碰就漾开。olo 是其中一只。
- **光鱼**：在空气里游的小光点，帮大家带口信，不说话，只绕圈。
- **小水洼**：会走路、走得很慢的小水洼，喜欢跟涟漪兽比谁更慢。

## 五、和产品功能的对应

| 产品功能 | 倒影国里的样子 |
| --- | --- |
| 一条消息 | 一圈涟漪 |
| 记住的事 / 日记 | 一枚彩色倒影，挂在小镇里 |
| 删除 / 别记了 | 那枚倒影化回水里 |
| 回访 | 属于你的那扇窗亮起来 |
| 成长阶段（原花园） | 雾蒙蒙的镜面 → 清亮的镜面 → 倒影小街 → 倒影小镇 → 双月之夜 |
| 寻宝（6 件） | 6 枚彩色倒影（id 不变，存档兼容） |

## 六、没来也没关系

倒影国不会因为你没来就枯萎、坏掉或生病。你不在的时候，olo 过自己的小日子：给新倒影取名字、看倒雨、跟小水洼比慢。你回来，那扇窗就亮了。
