# olo proto v5: unified little monster

Same weird-cute monster direction as v4, but silhouette and material rebuilt for **一体感** (one coherent creature, not glued-on parts).
Run: `python3 -m http.server -d web/proto` → `/v5/`.

Changes vs v4:
- Horns/tail/limbs grow out of the body via large smoothmin; same colour and lighting as the body (no coral horn paint).
- Dropped fangs, freckles, and the tip curl — weirdness lives in proportion and expression.
- Asymmetry kept but dialed down (left horn slightly longer).
- Rounder bean body; short limbs hug the torso; tail is a body extension.
