# olo v2 视觉质量标准（自查清单）

参照：Awwwards / FWA 获奖站（单一焦点、克制 UI、动效有物理感）、庄周梦蝶池塘（倒影叙事、夜色、萤光）、Monument Valley（几何剪影 + 柔和渐变 + 大面积留白）、Alto's Adventure（分层山体大气透视、天色循环）、Sky 光·遇（体积感柔光、暖冷对比、发光粒子）、陪伴类 App（角色永远“活着”，任何输入都有反应）。只学质量，不抄任何素材/文案。

1. **构图**：竖屏三分。地平线在 45% 高处，olo 在上三分线附近；前景芦苇压两侧边角做框，中景 olo，远景三层山。UI 只占底部输入栏 + 顶部一行字。
2. **调色**：每个时段只有一组冷暖对：暖光（太阳/萤火/olo 内光）对冷阴影（山体/水）。饱和度中等偏低，不出现纯白/纯黑；暗部带蓝紫，亮部带奶油黄。末级做 lift/gamma、暗角、极轻颗粒。
3. **光照**：一个主光方向（太阳/月），所有高光、边缘光、水面金光路径都与之一致；olo 有窗形高光 + 点高光 + 菲涅尔边缘光 + 底部水面反光 + 内部焦散。
4. **景深**：远山边缘越远越软；前景芦苇和近处萤火虫是虚的（散景圆），焦点永远在 olo。
5. **缓动**：不用线性。镜头 easeInOutCubic / expo；角色全部用弹簧（有过冲）；UI 进出 cubic-bezier(.2,.8,.2,1)，错峰 40–60ms。
6. **次级动作**：olo 头顶尖儿滞后于身体（跟随+过冲）；落地压扁、起跳拉伸；眨眼偶尔连眨；视线先动眼、再带动脸、最后带动身体倾斜。
7. **微交互**：打字=近处小涟漪 + olo 好奇凑近看输入框；发送=气泡飞进镜子化成光点、落到 olo 身边起涟漪、olo 开心跳；点水=涟漪+olo 看过去；点 olo=被戳压扁+开心；久不理=犯困。
8. **环境动效**（不能有静止画面）：天色循环、云带漂移、星星闪、萤火/尘粒漂浮、芦苇随风（含阵风）、鱼影游过偶尔冒泡、水面细浪和金光闪烁。
9. **转场**：屏幕之间用“水波擦除”+ 镜头弹簧推拉，不硬切。
10. **性能**：所有效果都在一个全屏片元着色器里解析绘制（无模型、无贴图、无后处理多 pass），像素比上限 1.5，掉帧时自动降分辨率；目标 WKWebView 60fps。
