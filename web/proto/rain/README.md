# 雨窗主页背景（原型）

窗外是黄昏镜湖和生产版像素 olo（`web/pixel.js` 的 `drawOlo`，动画不变），中间隔着一块下雨的玻璃。
原创实现，原生 WebGL2，零依赖；没有使用参考 demo 的代码或素材。

- 打开：`/app/proto/rain/`（或任意静态服务器打开 `web/proto/rain/index.html`）
- 参数：`?debug=1` 显示帧率；`?form=` 换形态；`?seed=` 固定随机；`?reduced=1` 模拟“减少动态”；点击玻璃会落下一颗水滴
- 模拟：静止小水珠（持续落新的）+ 大水滴（变重后下滑、走走停停、合并、留下小水珠尾迹、擦掉路径上的水珠和雾）
- 渲染：水画成高度场 → 着色器求法线 → 每颗水滴对窗外场景实时折射；玻璃有雾，滑过的路径变清晰后慢慢重新起雾
- 性能：一次全屏绘制；DPR 上限 2，帧时间偏慢时自动降到 0.5 倍分辨率；页面隐藏时暂停；`prefers-reduced-motion` 时只画静止一帧
